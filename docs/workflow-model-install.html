装完后怎样让镜场读到模型

  1. 把文件放到实际运行 ComfyUI 的电脑上。Windows 便携版从 ComfyUI_windows_portable/ComfyUI/ 开始对照。连接远程 ComfyUI 时，文件也放在远程机器上。
  2. 重启 ComfyUI。在镜场首页或画布右上角打开「ComfyUI 环境」，选择这台机器并点「测试并切换」。
  3. 打开图片、视频或音频节点的「模型与工作流」，选择对应预设。若已有权重位于自定义子目录或曾改名，在配置中把缺失项映射到实际文件。
  4. 如果提示缺少节点，按节点名称安装相应插件或更新 ComfyUI。比如两段续接需要 AICG3D，Wan 2.1 的 MP4 输出需要 VideoHelperSuite。
导演台手动摆位、运镜、时间轴导出、360° 拖动查看、提取音轨与替换音轨都无需额外下载生成模型。导演台「AI 识图搭景」需另配支持图片输入的视觉模型服务。

适用于镜场 Gitee 和 GitHub 同步后的内置工作流。所有下载按钮指向魔搭的文件地址，已于 2026-11-20 抽读文件头并核对大小。大小按十进制计。自定义导入的工作流以其实际文件映射为准。
